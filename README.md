# Petstore API Testing: xUnit vs NUnit

Проект сравнивает два тестовых фреймворка .NET — xUnit и NUnit — на примере публичного API Swagger Petstore.

## Требования

- .NET 8 SDK
- Visual Studio 2022 или более новая версия с поддержкой .NET 8
- Доступ к интернету для обращения к `https://petstore.swagger.io/v2`

## Структура

```text
Petstore-Testing/
├── xUnit.Tests/
│   ├── Tests/
│   │   ├── ApiTestHelper.cs
│   │   └── PetstoreApiTests.cs
│   └── xUnit.Tests.csproj
├── NUnit.Tests/
│   ├── Tests/
│   │   ├── ApiTestHelper.cs
│   │   └── PetstoreApiTests.cs
│   └── NUnit.Tests.csproj
├── screenshots/
├── Analysis.md
├── Questions.md
└── README.md
```

В каждом тестовом проекте находится 38 тестовых методов: проверки ресурсов Pet, Store и User. Для тестовых записей используются уникальные идентификаторы/имена; там, где создаются записи, выполняется попытка очистки.

## Запуск из терминала

Откройте терминал в папке решения и выполните:

```bash
dotnet restore
dotnet test xUnit.Tests/xUnit.Tests.csproj --logger "console;verbosity=normal"
dotnet test NUnit.Tests/NUnit.Tests.csproj --logger "console;verbosity=normal"
```

Либо откройте каждый `.csproj` в Visual Studio, восстановите NuGet-пакеты и запустите тесты через **Обозреватель тестов**.

## Что проверяется

- Pet: создание, получение, обновление, удаление, поиск по статусу и тегам.
- Store: получение инвентаря, создание, чтение и удаление заказа.
- User: создание, получение, обновление, удаление, вход/выход, создание списком и массивом.
- Положительные и отрицательные сценарии.

## Важные замечания

1. Petstore — публичный демонстрационный сервис. Он может быть временно недоступен, медленно отвечать или иметь нестабильное тестовое состояние.
2. API не всегда строго валидирует входные данные. Поэтому для отрицательных сценариев фактическое поведение может отличаться от ожидаемого по документации.
3. Тесты выполняют реальные запросы в интернет. При повторном запуске результаты и время могут меняться.
4. В `Analysis.md` внесите только фактические результаты собственного запуска.
5. Сохраните скриншоты результатов обоих запусков в папку `screenshots/`.
